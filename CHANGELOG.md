# Изменения

## MVP — 17 ноября 2026

- Локальный поток: веб/Telegram → FFmpeg → Faster-Whisper → классификатор → Ollama → Obsidian.
- TF-IDF + LogisticRegression для стилей «разговорный» и «официальный».
- Загрузчик текстовых аннотаций, разбиение по группам, обучение и локальный TTS→ASR;
  сравнение моделей использует одинаковые validation/test.
- Опубликованы агрегаты базового обучения: test accuracy 94,86%, macro-F1 0,9094.
  TTS-эксперимент ещё не выполнен.
- Единые зависимости uv; отдельные дополнения для аудио, GPU и обучения.
- Docker Desktop CPU/GPU, Windows-папка Obsidian и проверка CUDA без PyTorch.
- Совместимые PyAV/CTranslate2, проверка WAV-декодирования при сборке образа.
- Redis FIFO, квоты, идемпотентность, таймауты и отмена задач.
- Раздельные ключи API, Telegram allowlist и необязательный прокси.
- Стиль, метрики и короткие результаты в веб-интерфейсе и Telegram.
- Ollama остаётся во внутренней сети Docker, без конфликта с Windows-портом 11434.
- Документация запуска, эксплуатации и конфиденциальности; CI для тестов и CPU-образа.

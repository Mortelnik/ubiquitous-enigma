# Конфиденциальность и границы MVP

VoiceFlow AI рассчитан на запуск на одном локальном компьютере. По умолчанию API
доступен только на `127.0.0.1:8000`, Redis и Ollama — внутри сети Docker Compose.
Публикация сервиса в интернет и многопользовательская эксплуатация не проверены.

## Данные

- FFmpeg, Whisper, классификатор и Ollama обрабатывают записи локально.
- Загрузка моделей и публичных аннотаций требует сетевых запросов к их источникам.
- Telegram уже хранит входные сообщения на своих серверах. Для полностью локального
  ввода используйте веб-интерфейс.
- `BOT_SEND_RESULTS=false` — ответ только о сохранении. Значение `true` разрешает
  передачу стиля, метрик и фрагментов транскрипта/саммари через Telegram.
- `uploads/`, `data/`, `models/`, `reports/`, `obsidian_vault/`, медиа и `.env*`
  исключены из Git; разрешены только шаблоны окружения и `.gitkeep`.
- Build context Docker ограничен исходниками приложения и зависимостями uv.

Для завершённых задач действует `UPLOAD_RETENTION_HOURS` (24 часа по умолчанию,
0 отключает очистку). Заметки Obsidian сохраняются отдельно. Отчёты могут содержать
имена файлов и пути; `JOB_HISTORY_SEC` ограничивает срок статусов задач в Redis.
Не прикладывайте рабочие отчёты, аудио и транскрипты к публичным issues.

## Доступ

`VOICEFLOW_API_TOKEN` используется веб-клиентом, `VOICEFLOW_BOT_API_TOKEN` — ботом.
Токены должны быть разными. Telegram-бот требует токен BotFather и непустой список
числовых `BOT_ALLOWED_USER_IDS`; команды, callback и медиа проверяют этот список.
Веб-ключ хранится в памяти страницы и передаётся в `Authorization: Bearer`.

Квоты, лимиты файлов, длительности, FIFO и отмена описаны в
[docs/OPERATIONS.md](docs/OPERATIONS.md). Они ограничивают нагрузку в рамках MVP,
но не заменяют защиту сервиса при открытой публикации в сеть.

## Артефакты и ограничения

Загружайте только собственные доверенные `.joblib`: это сериализованные Python-
объекты. API не принимает пользовательские веса для загрузки классификатора.
Worker сейчас запускается от root внутри контейнера; приложение не изолирует
взаимно недоверенных арендаторов. Не меняйте параметры публикации портов без
отдельной проверки доступа и сетевой конфигурации.

Перед публикацией проверьте `git diff --cached` и список подготовленных файлов.
`.gitignore` не удаляет файлы из уже созданных коммитов. Если токен попал в историю,
его нужно отозвать у провайдера; не присылайте сам токен в публичное обсуждение.
Текущая проверка репозитория не является полным аудитом уязвимостей зависимостей.

# ДЗ 3. Классификация аудиосообщений по стилю речи

Команда 7: Шелест М.А. · Иванова Ю.С. · Романенко Д.Н. · Ишбулатова С.С. · Буянов Е.Э.

## 1. Задача и текущий статус

Вход — аудиосообщение; выход — **0 (разговорный)** или **1 (официальный)**.
Основной метод: TF-IDF + LogisticRegression. Усложнение — обучение на смеси
реальных транскриптов и транскриптов локально синтезированного аудио.
Определение подлинности голоса не является задачей этого классификатора.

MVP работает через веб и Telegram. **Базовый классификатор обучен на реальных
текстовых аннотациях без TTS**. Результаты ниже перенесены 17 ноября 2026 года из
локального `models/style_classifier.metrics.json` и метаданных модели. Отпечатки
текущих train/validation/test совпали с сохранёнными в модели; проверки разбиения
пройдены. Обезличенный снимок опубликован в
[`docs/results/baseline.json`](../docs/results/baseline.json).
Сравнение с TTS ещё не проведено; технические тесты не являются оценкой качества модели.

## 2. Данные и разметка

Источник: [OpenSTT Balalaika](https://huggingface.co/datasets/lab260/openstt_balalaika).
Скачиваются пять Parquet-файлов аннотаций; версия источника сохраняется в
`data/raw/download_manifest.json`. Полные аудиоархивы не скачиваются.
На странице источника указана лицензия CC BY-NC 4.0.

Слабые метки по домену: телефонные разговоры и сериалы — 0; лекции и публичные
выступления — 1. Предоставленные метки имеют приоритет. Радио, YouTube, художественные
истории и аудиокниги исключены из автоматической разметки. Домен не гарантирует стиль
каждой реплики. Указанные ранее размеры старого обучающего набора к новому эксперименту не относятся.

Фильтры: MOS >= 4.0 и один диктор при наличии значений; неизвестные значения допускаются.
Нормализация оставляет русские буквы и пробелы, длина — 3–300 слов.
Повторы текстов удаляются, противоречащие метки приводят к ошибке.

## 3. Разбиение и метод

Целевые доли групп: 70/15/15. Доли строк отличаются: крупные группы остаются целыми;
фактический train содержит около 94,2% строк. Связанные записи объединяются до разбиения;
тексты, пути и доступные ID групп не должны пересекаться между train/validation/test.
Словарь TF-IDF обучается только на train. Разбиение воспроизводимо с seed=42.

Pipeline: объединение словесных TF-IDF 1–3-грамм и символьных TF-IDF 3–5-грамм
(`char_wb`), затем LogisticRegression (`C=2`, `max_iter=2000`, `solver="liblinear"`,
`class_weight="balanced"`, `random_state=42`). Балансировка 1:3 сэмплированием
в этом варианте не применяется. CNN и ансамбль не используются.

Артефакт содержит полную предобработку, модель, версии и метаданные эксперимента.
Постоянный классификатор большинства обучается на реальном train и одинаков
для обеих постановок. Accuracy анализируется вместе с метриками обоих классов.

## 4. Эксперимент с TTS

1. Из исходного train выбираются фразы обоих классов, сначала до 200 на класс.
2. Локальный TTS создаёт WAV; метка стиля сохраняется, `is_synthetic=true` указывает происхождение.
3. Faster-Whisper получает `asr_text`; модель и язык ASR согласуются с приложением.
4. Только эти ASR-транскрипты добавляются в обучающую выборку второго эксперимента.
5. Validation/test остаются неизменными, их отпечатки проверяются и сохраняются.

Проверяются принадлежность исходных фраз train, совпадение меток/групп и отсутствие
пересечений ASR-текста с отложенными выборками. Голос, модель ASR, объём аугментации
и замечания по прослушиванию указываются после запуска. Сам факт синтеза не делает
пример разговорным или официальным: стиль задаётся исходным текстом.

Все метрики в таблице — в диапазоне 0–1. Прочерки обозначают не выполненный
эксперимент, а не нулевое качество. Постоянный baseline всегда предсказывает класс 1.

Подробные метрики базовой модели на test:

| Класс | Precision | Recall | F1 | Support |
|---|---:|---:|---:|---:|
| 0 — разговорный | 0,9204 | 0,7893 | 0,8498 | 337 |
| 1 — официальный | 0,9539 | 0,9846 | 0,9690 | 1 492 |

Confusion matrix: строки — истинный класс, столбцы — предсказанный:

| Истинный класс | Предсказан 0 | Предсказан 1 |
|---|---:|---:|
| 0 | 266 | 71 |
| 1 | 23 | 1 469 |

Класс 1 преобладает, особенно в train. Поэтому accuracy недостаточно: у
разговорного класса пропущено 71 из 337 реплик, recall составляет 78,93%.
Основные показатели для сравнения — macro-F1 и метрики обоих классов.
Версия scikit-learn сохранённой модели — 1.9.1; SHA-256 артефакта и отпечатки
выборок приведены в опубликованном JSON. Веса в Git не включены.

Кандидат выбирается **только по validation macro-F1**, при равенстве — модель без TTS.
Test не участвует в выборе и используется для итоговой оценки. Для TTS также нужны
confusion matrix и precision/recall/F1 каждого класса. Рост качества после TTS
не гарантируется; отрицательный результат тоже фиксируется.

Все приведённые оценки относятся только к опубликованным отпечаткам выборок;
при изменении разбиения или исходных данных эксперимент нужно повторить.

## 6. Анализ ошибок и ограничения

После запуска разберите ошибки каждого класса по доменам: деловые телефонные
реплики, разговорные вставки в выступлениях, ошибки ASR и сомнительные доменные метки.
Приведите обезличенные примеры без коммерческих данных. Отдельно оцените несколько
вручную размеченных реальных голосовых вне обучения и настройки параметров.

Итоговые ограничения: слабая разметка по доменам, возможный дисбаланс, неполные ID
дикторов, отличие записей Telegram от корпуса и артефакты конкретного TTS-голоса.
Тесты программы проверяют корректность процесса, а не качество ASR/TTS или обобщение модели.

## 7. Интеграция и воспроизводимость

Telegram/веб → FFmpeg → локальный Whisper → классификатор → выбор промпта → локальная
Ollama → Obsidian. Для класса 0 используется `prompt_2`, для класса 1 — `prompt_1`.
Диаризация необязательна. Исходные сообщения Telegram уже находятся на серверах Telegram;
для строго локального ввода предусмотрена веб-страница.

Установка и запуск выполняются через uv, зависимости зафиксированы в `uv.lock`.
Команды скачивания, обучения, TTS, сравнения, выбора модели и Docker приведены
в [RUNBOOK.md](RUNBOOK.md). В сервис подключается `models/style_classifier.joblib`.

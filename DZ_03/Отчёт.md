# Домашнее задание 3. Классификация текстовых сообщений по стилю речи

**Кейс 1 — Классификация аудиосообщений на «разговорные» vs «официальные».**
Команда 7: Шелест М.А. · Иванова Ю.С. · Романенко Д.Н. · Ишбулатова С.С. · Буянов Е.Э

**Ссылка на репозиторий:** https://github.com/Mortelnik/ubiquitous-enigma
**Ноутбук с кодом:** `model.ipynb`

## 1. Описание датасета

Для обучения модели классификатора использован датасет OpenSTT Balalaika [HuggingFace](https://huggingface.co/datasets/lab260/openstt_balalaika), а именно блок с русской речью.

### Покрытие и состав

| Параметр | Значение |
|---|---|
| Всего в датасете | 450 415 записей (431,4 часа аудио) |
| Размер для скачивания | 10,6 ГБ |
| Записей после нормализации | 275 252 записи (61% от исходного) |
| Для обучения использовано | 77 407 записей |
| Класс 0 = «разговорный» | 1 622 записи (телефонные звонки, публичные серии) |
| Класс 1 = «официальный» | 75 785 записей (публичные выступления, лекции, аудиокниги, истории) |
| Медианная длительность сегмента | 6,4 сек |
| Медианное число слов в сегменте | 14 |

Структура записи: `filepath` (путь к аудио), `mos_pred` (качество NISQA), `is_single_speaker` (один диктор), `punct` (транскрипт с пунктуацией), `domain` (домен-источник).

Из дата сета не использованы домены ютуб, радио, так как для них характерно использование и разговорного и официального стиеля вперемешку.

### Качество данных: нормализация и технические параметры

- **Фильтр качества:** NISQA MOS >= 4,0 (шкала 1–5), медиана по отобранным 4,35
- **Доля «шумных» сегментов:** 39% отсеяно фильтром (MOS < 4,0, несколько дикторов, музыка на фоне — по данным BALALAIKA)
- **Техническая нормализация:** одиночный диктор (pyannotate-диаризация), отсутствие музыкального фона

### Качество транскрипций

Транскрипты автоматические в датасете автоматические, что соответствует ожидаемому входному формату в нашем проекте с телеграмм ботом, в который текст попадается после транскриции от Whisper.

## 2. Предобработка данных

Использован метод нормализации + TF-IDF (словесные и символьные n-граммы).

1. Текст приведен к нижнему регистру, удалена пунктуация и цифры.
2. Словесные n-граммы (1–3) — ловят устойчивые фразы («уважаемые коллеги», «в соответствии с»)
3. Символьные n-граммы (3–5, char_wb) — ловят морфологические маркеры официально-делового стиля (суффиксы -ованный, -ение, -ающий)
4. Балансировка классов 1:3 сэмплированием мажоритарного класса

## 3. Классификация

### Метод

1. Основной классификатор:** TF-IDF + LogisticRegression (без трансформеров).
2. Ансамбль: взвешенное усреднение вероятностей LogisticRegression и CNN-классификатора на случайных эмбеддингах; веса подобраны на валидации перебором с шагом 0,05.

### Обоснование выбора метода

К сожалению, BERT как SOTA использовать нельзя, поэтому был использован классический подход.

### Результаты

| Модель | Accuracy (val) |
|---|---|
| LogisticRegression (TF-IDF слова+символы) | ~0,937 |
| CNN | ~0,85 |
| **Ансамбль LR + CNN** | **~0,94** |


## 4. Анализ ошибок

Доля ошибок составила 6%, в основом в следствии нескольих причин.

- Телефонные реплики с деловым содержанием, например в техподдержку, где звонящий говорит в разговорном стиле, но получается ответ условно говоря по официальном скрипту.
- Публичные выступления, где спикер часто использует слова-паразиты в речи, что смещается класс с 1 в 0.
- Сам дата-сет требует ручной доразметки в нескольких доменах, полностю автоматической разметки у авторов, судя по всему, не вышло.

## 5. Обработка данных после классификации

После обучения и предсказания на тесте вычислена confusion matrix, ошибка сгруппированы по принадлежности к домену, выведены примеров ошибок для лучше интерпритируемости результатов, дополнительно прозведена визуализация топ-слов каждого класса . Эти шаги реализованы в `model.ipynb`, разделы 3–6.

## 6. Выводы

- **Метод:** TF-IDF (слова 1–3-граммы + символы 3–5-граммы) + LogisticRegression, ансамбль с CNN
- **Обоснование:** различия разговорного и официально-делового стилей хорошо видны по лексике и морфологии; классический метод интерпретируем, быстр, воспроизводим
- **Фактическая точность:** ансамбль 95,81% на тесте
